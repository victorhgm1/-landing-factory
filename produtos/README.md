# /produtos — fonte de verdade
1 pasta por produto, slug em kebab-case sem acento. Dentro: só o `produto.yaml`.
- O yaml é a ÚNICA fonte de conteúdo da página — texto nunca vai direto no template.
- Molde oficial: `receitas-15min/`. Copiar a pasta e editar.
- Antes de qualquer deploy: nenhum campo pode continuar `SUBSTITUIR`.
- `linha:` define a paleta sozinha (corpo, cozinha, bolso, rotina, garra, mente, casa).
